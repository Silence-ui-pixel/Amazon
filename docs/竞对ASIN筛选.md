# 第三步：确定竞对 ASIN

前置：保存第一步词根和第二步核心大词。在“筛选竞对 ASIN”面板收集候选。方法一、方法二由人工核对商品主图、用途、规格与价格段后保存；方法三按固定门槛自动确认。

## 三种来源

1. 市场调研：填写已调研的 ASIN，以空格、逗号或换行分隔，一次最多 100 个。自动统一大小写、去重并排除本品 ASIN。
2. 前台重复 ASIN：自动使用全部已确认核心词，显式搜索各词第一页前 30 个自然商品，排除广告。先按跨词命中数从高到低排序；命中次数相同时，复用前面商品词分析中该 ASIN 与自家商品的四维综合分排序，同一 ASIN 有多条有效证据时取平均分，无证据者排在同次数且有证据者之后；最后按 ASIN 保证顺序稳定。不再限制前 10 个。选择多个词时，候选至少命中两个词；只有一个词时会提示没有跨词重复证据。采集失败或结果不足会保留提示，不补造商品。
3. 商机探测器：系统读取第二步全部核心大词，逐个进入亚马逊后台 → 商品 → 研究商品 → 商机探测器并搜索。系统读取购买意图名称、热门关键词与指标，结合本品已确认的用途、款式结构和规格只选择最相关的一项；即使全部匹配度偏低，也选择相对最接近项并保存理由与置信度。随后点击“查看详情”，切换“商品”页，将时间范围设为最近 30 天并下载 CSV。原件业务文件名为 `筛选竞对ASIN-<核心大词>.csv`。系统先按 CSV 中最近 30 天平均售价筛选本品参考价 ±15%（含边界），只有价格和币种合格的 ASIN 才读取详情并计算四维相关度；综合相关度严格大于 50 才自动确认为竞对，等于 50 不通过。跨核心词 ASIN 只分析一次并保留全部来源，最终按相关度保留前 100 个。手动 CSV 导入仍只是备用候选来源，不自动确认。

搜索结果保留站点、关键词、自然位置、来源页和采集时间。可显式点击“读取商品主图与当前价”补充商品详情；此操作会重置该商品的人工判断，需要重新核对。刷新页面和读取历史只读取已保存数据，不调用模型或重新采集。

## CSV 格式

支持 UTF-8、逗号 / 制表符 / 分号分隔、最多 500 个商品、文件小于 2 MB。ASIN 为必需列；其他缺失字段显示未知。

```csv
ASIN,Product Name,Average Selling Price (90 days),Currency,Image URL
B012345678,Cooling blanket,23.00,USD,https://example.com/blanket.jpg
```

支持 Title、Price 和常见中文列名。价格用 `23.50` 小数格式，币种用 `USD` 等三字母代码。90 天平均售价会单独标记，不冒充当前价。重复 ASIN、价格与币种标记冲突、格式错误会拒绝整批导入，不部分写入。

## 人工筛选与价格

填写本品参考价、币种及浮动范围（默认 ±15%，边界包含在内）。价格状态在保存时由服务端计算；修改参考价后需重新保存。

新候选集优先继承第一步已确认四维基准中的售价与币种；旧任务没有已确认基准时，使用最初输入的参考价。同一候选工作区追加商品时，保留第三步已保存的人工价格调整。

- 方法一、方法二及手动 CSV 导入的商品可选待核对、保留、排除。保留或排除需填写理由；最终保留 1 至 100 个。方法三批量自动筛选会生成系统理由并直接确认。
- 未知价格、未知币种、币种不同或超出价格段时，保留必须补充价格核对说明。系统不自动换汇。
- 商品页币种依据价格主体中的明确证据；裸 `$` 或 `¥` 无法确认币种时显示未知，币种证据冲突也显示未知。
- 未保存的人工修改会阻止追加候选与详情采集；可先保存或明确放弃修改后读取。第二步临时取消再勾回、读取相同历史选择会保留第三步草稿。

## 保存与接口

PostgreSQL 保存不可变版本快照，携带第二步实际选择 ID。第二步保存新选择后旧竞对标记过期，需要追加当前候选并重新核对。并发版本不一致返回 409，避免覆盖更新。同内容确认重试可恢复成功结果。

基础路径：`/api/v1/projects/{project_id}/pipeline-runs/{run_id}/competitors`。

| 接口 | 用途 |
| --- | --- |
| GET 基础路径 | 只读恢复最近快照及过期状态；尚未建立返回 404 |
| POST 基础路径/discover | 显式人工添加、自然搜索、CSV 导入或详情补全；携带 expected_version |
| POST 基础路径/poe-download-all | 下载全部核心词商机数据，自动筛选并确认竞对；携带 expected_version 和 retry_keywords。默认空数组表示全部执行；失败项可只提交对应核心词单独重试，其他成功原件经 SHA256 校验后复用 |
| PUT 基础路径/selection | 保存参考价、币种、浮动范围和完整人工判断；携带 expected_version |

本次验收覆盖隔离数据库、模拟外部来源和真实浏览器页面。真实 Amazon 搜索、商品详情与账号下 Products 导出仍取决于网络、登录及页面结构，未作线上实采验收。

方法三按核心词保存 `intent_collection`（读取购买意图）、`intent_selection`（选择意图）、`download`（下载 30 天商品表）或 `csv_validation`（校验表格）阶段。失败时页面保留已选购买意图、理由、置信度和错误原因，并提供“只重试此核心词”。
