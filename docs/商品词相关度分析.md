# 商品词相关度分析

商品词是“能搜索到本品同类产品的完整、准确品类词”。新研究在确认商品资料与四维基准后，默认生成 3～5 个有效候选（确实不足可以更少，上限 10 个），并自动分析，不需要用户逐个勾选启动。保留能独立表达品类的单词，如 mug；不把 dumbbell rack 拆成 dumbbell 或 rack。生成与人工编辑均检查泛词、明显主体错误及理由自我否定；模型语义判断仍需真实样本验证。

每个商品词在美国站搜索，排除广告后按自然顺序跨页去重，最多采集前 30 个 ASIN；不足 30 个按实际取得数量。每个商品提取用途、款式结构、规格和可靠价格，并与本品逐项比较。

综合相似度的权重固定为：用途 35%、款式结构 35%、规格 20%、价格 10%。价格相似度为：

`max(0, 100 - abs(搜索商品归一价格 - 本品归一价格) / 本品归一价格 × 100)`

只有明确包装数量才换算单件价格。用途、款式结构或规格任一主维度缺失时，该商品从分子和分母同时剔除；价格、币种、包装数量或计价单位不可比时不再剔除商品，而是将前三个主维度按 `35:35:20` 重新归一到 100 分，页面明确显示“价格未参与”。价格可比时仍使用用途 35%、款式结构 35%、规格 20%、价格 10% 的四维公式。优惠券价、订阅价和区间价不是可靠当前价。纯图片任务仍必须由用户提供本品参考售价，模型不得估价。

综合相似度严格大于 60 才计为高相关，等于 60 不计入。商品词相关度为：

`高相关商品数 / 有效样本数 × 100%`

可信度按有效样本数划分：20～30 为高，10～19 为中，1～9 为低，0 为无有效样本且不参与排名。全部已完成且商品词相关度严格大于 40% 的候选入选，等于 40% 不入选；例如 30 个有效样本中 12 个高相关不通过，13 个高相关通过。单个候选失败不阻塞其他候选，但结果标记为不完整；失败候选不能以 0% 参与排名。

新接口为 `/product-profile`、`/product-term-candidates` 和 `/product-term-analyses`。旧 `/root-*` 路由和旧证据继续只读兼容，不会因查看或刷新而重新搜索或重复调用付费模型。

## 候选修正、进度和人工处理

页面提供“修改 / 补充商品词”与“重新生成并验证”入口。`PUT /product-term-candidates` 提交 `expected_version` 与完整候选数组；`POST /product-term-candidates/regenerate` 提交 `expected_version`。旧候选快照与分析证据保留，已确认商品资料不变；旧选择清空，当前结果按候选版本隔离。未变化的商品词保留 ID，仅在本品基准及比较规则一致时复用已完成证据；新增或替换的词使用新 ID 并重新采集。分析或流程运行中禁止修改候选；已产生 ABA 或核心词产物的研究要求新建研究，避免下游错配。

`POST /product-term-analyses` 后台执行，立即返回 queued；重复提交复用当前任务。普通继续仅补跑未完成候选；显式 `refresh=true` 创建新分析并保留上一份结果。`GET /product-term-analyses/history` 与 `/product-term-candidates/history` 只读取历史。页面展示搜索页数、自然商品数、已取得详情数、失败数、已评分数和各词未入选原因，不用等待状态冒充无有效样本。

页面轮询使用 `/product-term-analyses/latest?summary=true`，历史列表同样只返回摘要；不重复传输全部商品原始详情。展开某词时通过 `/product-term-analyses/{analysis_id}/candidates/{candidate_id}` 按需读取该词的搜索证据和逐商品评分。完整分析仍由按 ID 读取接口与数据库保留，不因摘要展示丢失。

完整分析无合格项时标记 `awaiting_review`，自动流程暂停在 `product_term_analysis` 人工门，显示已处理数量和 0 个达标。重复继续复用已完成证据，不重复调用模型；补充准确品类词并验证通过后才继续。人工选择接口同样要求真实证据中高相关商品比例严格 `>40%`，不能通过手动勾选绕过门槛。生成的原始模型回复、质量检查结果及诊断编号随候选版本保留；结构异常也在模型诊断目录保留原始回复。

## 第二步复用与边界

第一步商品词采用最多 30 个自然商品、四维权重、单商品综合分严格 `>60`、无效样本同时退出分子分母的规则，保留全部词级相关度严格 `>40%` 的已完成候选。第二步核心大词使用独立的规则版本及入选门槛，详见 [核心大词筛选](核心大词筛选.md)；本次第一步门槛调整不改变第二步规则。没有有效样本的词不能入选。

第二步自动保存全部合格词；页面分页只控制显示，已选项在原表格置顶，不构成保存上限。新分析使用 `hot-search-core-v1`，单独 POST 只创建 queued，由 LangGraph 调用 execute 执行，GET/刷新不发起模型或搜索。重启或超时后的未知付费结果不自动重发，基准或选择变化后历史结果只读且 stale。完整接口、状态与旧 `legacy-root-v1`/`core-terms-v1` 边界见 [核心大词筛选](核心大词筛选.md)。
